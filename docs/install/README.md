# Install Workestrate

[Overview](../../README.md) · [First workload](../getting-started.md) · [CLI guide](../cli.md)

Workestrate currently targets **x86_64 Linux**. Nix supplies the CLI and its
matching Microsandbox runtime; workloads run with KVM.

### [Linux with Nix →](linux.md)

Keep your distribution. Add Nix, prepare KVM, and install Workestrate.

### [NixOS →](nixos.md)

Configure the host declaratively, then provision Workestrate for your user.

### [Windows →](windows.md)

A short detour through Linux, with an experimental WSL option for the curious.
